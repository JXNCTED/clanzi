## 偏差与未解决限制

1. macOS 源码、打包及验证不在当前实现范围内。
2. Linux 直接使用内核 hidraw 和 uinput API，而非 HIDAPI；打开厂商节点前核对描述符。所有合成输入使用独立虚拟键盘，不依赖 X11 工具。
3. Linux hidraw 不提供强制独占。实现使用协作式 `flock`，不能检测或阻止不遵守该锁的应用同时打开接口。使用前须关闭 Studio 及其他客户端；更严格的占用检测要求尚未完全满足。
4. 100 ms 静默窗口不能证明历史输入已全部排空；协议没有序列号或时间戳，无法区分任意迟到的历史按下。T12 仍阻止正式验收，不能声称物理交接保证无双发。
5. 通过 logind 的 `dbus-monitor` 观察睡眠通知，未持有延迟抑制器；睡眠前完成清理及通知丢失后的恢复仍须验证。监视启动错误会记录到日志。
6. 原子替换成功后若目录同步失败，记录 `CONFIG_DIRECTORY_SYNC`，仍以 rename 为提交点。该少见故障下不保证掉电持久性，也不谎报旧磁盘字节仍是当前版本。
7. Wayland／Xorg 的实际修饰键协调、设备路由、虚拟键盘注册时间、原生界面渲染及安装均未验证。一秒注册宽限只是调度预防措施，不能证明合成器已经就绪。

## 硬件验证步骤

1. 记录应用版本、会话（`Wayland` 或 `Xorg`）、可获得的 AU05 固件、实际时间及本机日志路径。退出其他 AU05 应用。
2. 安装权限规则，重新插入一个接收器。导入 `examples/keymap.json` 并明确保存，确认状态达到转发中。
3. 聚焦空白文本编辑器或输入事件查看器。按顶部键，等一秒；中部键，等一秒；底部键，等一秒；旋钮按下，等一秒；右转一格，等一秒；左转一格。重复 20 次，不长按电源键。
4. 在能观察相应效果的应用里测试 Ctrl+C、Shift+Tab、Alt+Left 及合适的 Super 快捷键，并交错真实修饰键。检查短按和持续按住的按下/松开时序，并测试 Handy 按住说话。
5. 合成组合键处于按下期间，测试暂停、断连、替换配置、撤销权限和退出；检查不补发旧动作，释放失败保持可见。
6. 测试启动前持键、延迟报告和明确重新同步。出现任何历史动作补发或双发都判定 T12 失败。
7. 关窗运行一小时，检查睡眠唤醒和无托盘重开，测量 100 次孤立动作，再执行基础序列。在另一个目标会话重复完整流程。
