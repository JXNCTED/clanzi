# 配置与输入行为

[English](configuration.md) · [README](../README.zh.md)

## 文件与保存

配置位于 `$XDG_CONFIG_HOME/olanzi-cross-platform/`；XDG 未设置或为相对路径时使用 `~/.config/olanzi-cross-platform/`：

- `keymap.json`：已保存映射，仅在明确保存时创建。
- `preferences.json`：界面偏好，与映射分开保存。
- `logs/`：本机诊断日志，最多两个 5 MiB 文件，不记录普通键盘文本或完整映射。

编辑只修改草稿。导入替换草稿，导出使用已保存配置。保存时校验并冻结整份草稿，写入并同步临时文件后原子替换。写入失败保留草稿和旧生效映射。损坏的本机文件会保留；明确修复保存时先创建唯一的 `keymap.invalid-YYYYMMDD-HHmmss-N.json` 备份。

六项“不执行动作”是有效配置，保存后会接管并丢弃相应动作。停止转发请使用暂停或退出。删除个人数据前先退出应用，再删除配置目录。

## 按钮与旋转行为

三个按键和旋钮按下立即转发物理按下/松开事件，没有模式选项、最短时长或长按阈值。重复按下报告会被忽略，同一轮读取中的按下/松开仍产生完整输出。不额外添加应用级连发计时器。

旋转动作产生 40 ms 点按，相邻点按至少间隔 10 ms，先进先出队列最多容纳 32 个待执行动作。按钮持键不会阻塞队列。共享输出键保持按下，直到最后一个使用者释放；对已按住的键点按不会产生新的按下边沿。持有的修饰键可能影响其他快捷键。

暂停、睡眠、替换映射、退出、断连、离线或状态未知，以及输出/心跳故障会释放持有按键并清空队列。释放失败保留清理债务，清理成功并重试后才恢复转发。重新同步前须松开已观察到的持键。若设备在线时丢失松开报告，可暂停或退出以释放卡住的快捷键。

## JSON 兼容性

两个支持版本均使用 `olanzi-cross-platform-keymap` 格式、`AU05` 设备和完整六控件映射。文件上限为 64 KiB；未知或重复字段、无效按键/修饰键以及不支持的版本会被整份拒绝。修饰键顺序为 Ctrl、Shift、Alt、Super。

- 版本 1 接受 `key` 和 `none`。按钮的 `key` 跟随实际按压时长，旋转的 `key` 为定时点按。
- 版本 2 另外接受仅用于按钮的旧 `hold` 动作，行为与按钮 `key` 相同。已有文件无需启动时重写或手动保存。
- 新映射使用 `key`。编辑器修改旧 `hold` 的按键/修饰键时保留其类型，只要还有 `hold` 就使用版本 2。旧的仅点按程序可能以不同方式处理版本 1 按钮，并拒绝版本 2 文件。

完整格式见[样例](../examples/keymap.json)。可通过以下命令校验文件：

```sh
cargo run --offline --bin clanzi-validate -- examples/keymap.json
```
