# 按钮跟随实际按压时长

[English](hold-mode.md) · [README](../README.zh.md)

## 配合 Handy 使用

顶部、中部、底部按键和旋钮按下自动跟随物理按下与松开。短按产生短按，按住则持续保持快捷键，松开才释放。不需要选择模式，也不需要长按判断阈值。两个旋转方向继续发送 40 ms 点按。

重启更新后的程序后，已有映射直接生效。请先退出旧 clanzi 实例；关闭窗口仍会在后台运行。配合 Handy 时，按需分配其录音快捷键，并在 Handy 中使用按住说话，不需要 CLI 切换命令。

## 运行行为

按钮事件立即转发，独立于旋转点按队列。重复按下报告会被忽略；同一轮读取中的按下和松开也会产生完整输出。按钮没有最短按压时间，也没有 40 ms 自动释放计时器。

多个按钮和正在执行的旋转点按可以共享普通键或修饰键。每个输出键只按下一次，最后一个使用者松开后才释放。对已经按住的键发送旋转点按不会再次产生按下事件。与物理键盘一样，按住的修饰键可能影响其他快捷键。此次修改转发按下/松开状态，不额外添加应用级连发计时器。

暂停、睡眠、配置替换、退出、接收器断开、设备离线或状态未知、输出或心跳故障都会取消持键和排队点按。释放失败会保留清理债务并锁定转发，直到清理成功且用户重试。恢复时不会重新按下已观察到仍被按住的按钮，请先松开它。设备保持在线时，无法通过超时判断是否丢失松开报告而又不截断正常长按；若快捷键卡住，可暂停或退出以释放。

## 配置兼容性

用户此次明确要求的行为替代原始规格中的按钮固定时长点按，以及上一版的逐按钮模式选择。已有文件直接接受，不需要启动时重写或手动保存。

- 版本 1 的 `key` 动作在四个按钮上跟随实际按压时长，在旋转方向上仍为定时点按。`none` 仍忽略该控件。
- 继续接受上一版产生的版本 2 文件。其中仅用于按钮的 `hold` 动作与按钮上的 `key` 行为相同。修改键位或修饰键时保留这些旧动作，编辑器不再提供模式选项。
- 新映射使用 `key`，不需要新字段或版本升级。包含旧 `hold` 动作的文件保持版本 2，使不支持该动作的旧应用明确拒绝，而不是错误解释。
- 大小限制、严格字段校验、重复字段拒绝、修饰键排序，以及禁止旋转 `hold` 动作的规则保持不变。
- 导出保留已保存配置。旧的仅点按 clanzi 可能把版本 1 按钮映射解释为固定时长点按；跟随实际时长需要使用本次更新后的程序。

## 验证

确定性测试覆盖普通版本 1 按钮映射的 1、39、40、41、200、1000 ms 按压，全部四个按钮的持续数秒持键，旧版本 2 兼容，重复与同轮按下/松开，共享按键，旋转点按并行，清理失败和停止/恢复行为。AU05 到 Handy 的实际操作仍需桌面硬件验证。
